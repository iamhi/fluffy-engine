# Lite-data-excavator

This app is a service on which user can schedule jobs.
And have local or external executors accomplishing those jobs.

### Wants

- JWT authentication
- JOB CRUD
- Job scheduler
- Job executing by different systems/services/tools
- Job executer

### Feeders?

- Brave api
- Duckduckgo api
- Google search api
- Other search api
- Webscrap wiki or wiki api
- Reddit api or reddit scrap
- Polygon api
- Kalshi and other bettings api (Polymarket)
