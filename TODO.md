# Lite-data-excavator

This is a demo app which will use (S)LLM to summarize data found on the web.
The idea is to utilize multiple search results and come to a short conclusion.

### Wants

- Brave api
- Duckduckgo api
- Google search api
- Other search api
- Webscrap wiki or wiki api
- Reddit api or reddit scrap
- Polygon api
- Kalshi and other bettings api (Polymarket)
